# 🎵 Music Player Web App

A responsive and interactive Music Player web application that allows users to play, pause, and control audio tracks through a clean and user-friendly interface. This project helped me understand audio handling in JavaScript and dynamic UI updates.

---

## 🚀 Features

- Play and pause music tracks
- Next and previous track controls
- Display current track title
- Responsive design for all devices
- Clean and minimal user interface

---

## 🛠️ Built With

- HTML5 – Structure
- CSS3 – Styling and responsiveness
- JavaScript – Audio control and DOM manipulation
- HTML5 Audio API

---

## 📂 How It Works

1. User selects or plays a track
2. JavaScript controls audio playback using the Audio API
3. UI updates dynamically based on play state and progress
4. User can control playback using buttons

---

## 🎯 Learning Outcomes

- Working with the HTML5 Audio API
- Handling play, pause, and track switching
- Syncing UI with audio state
- Improving frontend logic and structure
